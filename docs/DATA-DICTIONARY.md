# 保费补退定义

每份保单有且仅有一条issue基线。change按effective、责任、version选版；同生效日同版本矛盾拒绝。cancel必须引用同保单的change，取消整份变更，不按录入顺序覆盖。区间为[start,end)。年度保费按所在自然年365或366日拆分，跨年强制切段。先求每段精确保费，再最大余额法分配到分，使段合计等于保单总额。paid为已收金额，总应收减已收为补退额，正数补缴、负数退费。

## 通用采信约定

CSV按UTF-8 BOM、UTF-8、GB18030回退，保留逻辑记录结束行号；引号内换行由CSV解析。重复表头单独计数，列数不齐隔离。编码与ID按字符串保形。缺失哨兵为 `-`、`N/A`、`NULL`、`未知` 与空串；不得作为零。数值先NFKC归一、去千分位，再用Decimal。日期采用ISO；时间必须带偏移并转UTC。空文件、全空行、仅表头分别返回EMPTY_FILE、BLANK_FILE、HEADER_ONLY。

重复键为(id,version)，完全相同行去重；同键内容冲突则整组隔离，不取最后一行。行数对账：输入=采纳+隔离+空行+重复表头+完全重复。运行幂等键由输入字节、参数与规则版本计算。

## 佣金追偿定义

追溯更正后实收大于应收（REFUND）的保单产生应追佣金：应追佣金=(实收−应收)×佣金率，按ROUND_HALF_UP精确到分。佣金率、本期结算期间、原结算期间与关账截止月由运行参数`commission_rate`、`settlement_period`、`original_period`、`closed_through`给出；佣金率缺省0.10且须在0到1之间，期间格式为YYYY-MM。原结算期间缺省取保单起保月，本期结算期间缺省取该保单已采纳批单与撤销批单生效月的最晚月。

判定规则：原结算期间未关账（默认与本期结算月相同，或未被closed_through锁定）则回冲原结算单（REVERSE），抵扣期间为原结算期间；原结算期间已关账（默认早于本期即视为关账）则下期抵扣（OFFSET），抵扣期间为本期结算期间，本期也被锁定时顺延至关账截止月次月。跨两个结算月时，回冲将费用与渠道余额调整落在原期间，抵扣落在本期，两者影响不同，须逐笔记录抵扣期间。

每条计算记录写入commission块：应追佣金recover、处理方式method、抵扣期间offset_period、原结算期间original_period、本期结算期间settlement_period、原批改依据basis（已采纳批单与撤销批单号）。资金账给出应追佣金合计及回冲/抵扣拆分。同一更正重算幂等键相同，追偿只记一次；参数非法返回PARAMETERS且不落库，已存批次保留旧版；结案文件为每笔追偿写「佣金追偿」记录行，归档证据条数含追偿笔数，渠道对账链不断。
